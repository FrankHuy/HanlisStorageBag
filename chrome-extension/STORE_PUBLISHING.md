# Chrome 应用商店首次发布

当前版本 0.1.0。商店尚未创建条目，以下为提交材料及操作说明；实际注册、付款和送审由 Google 账号持有人完成。

## 操作顺序

1. 用打算长期维护插件的 Google 账号进入 [开发者后台](https://chrome.google.com/webstore/devconsole)，注册开发者并支付一次性注册费，金额以支付页为准。该账号必须开启两步验证，并完成后台要求的邮箱等验证。
2. 在本机 Chrome 通过“加载已解压的扩展程序”安装 `dist/`，用真实播放页完成一次识别、筛选、切集和校准检查。自动测试不能替代浏览器实测。
3. 在后台选择新增项目，上传 `releases/hanli-storage-bag-chrome-v0.1.0.zip`。可以直接下载 [线上安装包](https://hanli.hym.cc.cd/downloads/hanli-storage-bag-chrome-v0.1.0.zip)。不要上传名称带 `source` 的源码包。ZIP 根目录应直接有 manifest.json。
4. 填写商品详情、隐私、分发设置及测试说明。推荐免费、公开发布，语言为简体中文，分类按后台现有分类选择与观影工具相符的一项。
5. 图标使用构建后的 `dist/icons/icon-128.png`（128×128）。准备至少一张真实运行截图，建议 1280×800，可上传至多五张。小宣传图 440×280 是可选材料，以后台当前要求为准。截图应清晰展示实际插件，不宣称官方出品。
6. 提交审核；可选择审核通过后自动发布或手动发布。审核通过前没有公开安装地址。取得商店链接后再添加到网站入口。
7. 后续更新增加 manifest 中的 version，重新构建并上传到同一个条目；保持同一个扩展 ID，以保留用户和统计。

## 可复制的商品详情

名称：韩立的储物袋 · 追番助手

简述：观看凡人修仙传时，点击查询当前剧集对应的物品考据记录。支持 B 站剧集自动识别、章节校准与本地离线查询。

详细介绍：

```text
追番时，看看韩立此时已有哪些珍藏。

在 B 站《凡人修仙传》播放页点击插件，识别当前剧集，按对应小说章节展示已收录的物品持有记录和得失变化。

• 识别当前 ep 播放链接，排除预告片，支持播放页切集后的重新识别。
• 可选择观看前或观看后进度，默认观看前；支持手动校准小说章节。
• 按物品名称检索、筛选储物袋位置，查看已收录的得失与章节出处。
• 物品查询离线运行，设置及校准保存在本机；未知剧集可查询 B 站公开目录。

这是非官方同人考据工具，与原著版权方、动画出品方及 B 站无隶属关系。
当前提供第 1–197 集的第三方章节映射，后续剧集需补录或手动校准。小说物品档案为关键节点记录，仍有考据空档，不保证还原每一章的全部物品。动漫与小说改编可能不同；插件不识别视频中的具体播放时刻。
```

## 隐私页填写依据

单一用途：在用户观看《凡人修仙传》的 B 站播放页时，识别当前剧集并展示相应小说进度的物品考据记录。

| 权限 | 可复制的理由 |
| --- | --- |
| activeTab | 用户点击扩展后识别当前标签页 URL，提取 B 站播放链接中的剧集或季度编号，以匹配物品记录。 |
| scripting | 在用户授权的 B 站播放页运行随扩展打包的只读脚本，提取公开剧集元数据和当前选中剧集，不改变播放器。 |
| storage | 在本机保存观看前后模式、每集手动章节校准与公开剧集目录缓存，不做云端同步。 |
| https://api.bilibili.com/* | 使用剧集或季度编号请求 B 站公开目录，解析未收录的播放链接和刷新目录；请求不携带 Cookie。 |

远程代码：选择不使用远程代码。所有 JavaScript 随包提供；B 站接口只提供 JSON 数据，不能被执行为代码。

数据使用声明必须与提交时的实际代码及隐私政策一致：扩展读取当前 URL 和剧集元数据，在本地处理和缓存；向 B 站发出的请求包含 ep ID 或 season ID，不向开发者服务器上传浏览或查询记录。不要把“没有开发者统计服务器”写成“完全没有网络请求”。后台要求的数据类别及有限使用承诺应由发布者阅读说明后按实际行为填写，不能为了通过审核作不实声明。

## 安装量在哪里看

在开发者后台打开这个扩展 → Analytics → Installs & Uninstalls 查看安装和卸载；Impressions 查看商店曝光/访问；Weekly Users 查看用户统计，可按时间筛选并导出 CSV。用户统计不等于实际使用活跃度。

商店数据不能作为官网 ZIP 下载次数或“加载已解压”次数的统计，也不会把已有的手动安装追溯为商店安装。让用户从审核通过后的商店地址安装，才能用同一条目的商店统计观察增长。无需在插件中接入自行采集观看行为的统计脚本。
